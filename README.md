# Digital Portfolio ✨

A personal portfolio website bringing together digital marketing,
creative projects, AI experiments, and web development through
a Pinterest-inspired scrapbook design.

## Project Overview

The website presents projects, skills, and creative work in an
interactive, visually organised format. Visitors can explore
project case studies, browse a visual diary, and learn about
the thinking behind the work.

## Features

- **Project Gallery:** Filterable cards with detailed case studies.
- **Portfolio Carousel:** An interactive presentation-style deck.
- **Visual Diary:** A collection of photographs, graphics, and moodboards.
- **Skills Section:** Capabilities across marketing, content, and development.
- **AI Assistant:** Portfolio questions grounded in project information.
- **Résumé:** Preview and download options.
- **Contact:** Direct links and a validated enquiry form.

## Design Approach

Warm backgrounds, editorial typography, collage elements,
and subtle animations create a scrapbook-inspired experience.

The layout supports desktop and mobile browsing, with readable
content and accessible navigation.
